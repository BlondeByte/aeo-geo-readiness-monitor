Goal: Build AEO/GEO auditing workflow that evaluated webpages using headings, question based content, concise answers, lists, tables, data, citations and relevance indicators. 

No-LLM workflow that evaluates the structural "answer readiness" for AEO/GEO searches of webpages using observable HTML/content features

For each approved URL it extracts:
title and meta description
H1 / H2 / H3 counts
question-style headings
concise paragraphs immediately following headings
list count
table count
internal/outbound links
JSON-LD presence and schema types
FAQPage/HowTo/Article schema
tag
published / modified date hints
word count
average paragraph length
reference/source-like sections

A readiness score between 1-100 is created. No claims to predict any frontier LLMs, or any other answer engine's ranking/citations. This is for comparison/analysis only. 

RIGHTS GATE
Only rows where human_approved is YES are analyzed. Verify the rights/public-domain/reuse basis manually. Do not assume every page on a federal/government site is automatically public domain.
