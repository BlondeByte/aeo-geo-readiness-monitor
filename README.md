A deterministic, no-LLM workflow that evaluates the structural "answer readiness"
of webpages using observable HTML/content features.

For each approved URL it extracts signals such as:

- title and meta description
- H1 / H2 / H3 counts
- question-style headings
- concise paragraphs immediately following headings
- list count
- table count
- internal/outbound links
- JSON-LD presence and schema types
- FAQPage / HowTo / Article schema
- canonical tag
- published / modified date hints
- word count
- average paragraph length
- reference/source-like sections

It then creates a transparent heuristic score from 0-100.

IMPORTANT: This does not claim to predict ChatGPT, Google AI Overviews,
Perplexity, Claude or any other answer engine's rankings/citations. It is a structural
comparison heuristic.

*RIGHTS GATE

Only rows where `human_approved` is YES are analyzed.

Before recording:
1. Choose pages you are allowed to use.
2. Verify the rights/public-domain/reuse basis manually.
3. Put the basis and source rights URL in `urls.csv`.
4. Change `human_approved` from NO to YES only after verification.

Federal-government pages are often useful, but do not assume every element on
every .gov page is automatically public domain; third-party material can exist.

*SET UP
Terminal:

```bash
cd aeo_answer_readiness_auditor
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install --upgrade pip
pip install -r requirements.txt
```

Open the folder in VS Code:

```bash
code .
```

If `code` is not available, open VS Code manually and choose:
File -> Open Folder -> aeo_answer_readiness_auditor

*RUN THE ANALYZER

After at least one `human_approved=YES` row:

```bash
python3 analyzer.py
```

Outputs:
- `output/aeo_audit.csv`
- `output/aeo_audit.json`

*RUN DASHBOARD

```bash
streamlit run app.py
```

The dashboard reads the CSV generated by the analyzer. It does not call an LLM.

*RECORDING-FRIENDLY WORKFLOW

1. Show `urls.csv` and your rights fields.
2. Show one or two approved pages in the browser.
3. Explain the observable signals.
4. Run `python3 analyzer.py`.
5. Open `output/aeo_audit.csv`.
6. Run `streamlit run app.py`.
7. Compare high and low scoring pages.
8. Inspect one page manually to validate why it scored the way it did.
9. Explain limits: structural readiness is not the same as actual AI citation visibility.

*AFTER RECORDING

- Airtable: store historical audit runs
- n8n: schedule weekly/monthly audits
- Slack: alert on major score/content changes
- Page-change monitor: compare structural signals over time
- Actual citation-observation layer: separately track whether answer engines cite pages
